## 📌 Overview
This repository contains a comprehensive Exploratory Data Analysis (EDA) of the Sample Superstore dataset. The goal of this project is to uncover business insights regarding sales trends, profitability margins, and regional performance using Python.

## 🚀 Features
- **Data Cleaning:** Handling missing values, removing duplicates, and data type formatting.
- **Feature Engineering:** Calculating metrics such as *Delivery Days* from order and shipping dates.
- **Visualizations:** Utilizing `matplotlib` and `seaborn` for correlation heatmaps, bar charts, and count plots.
- **Business Insights:** Actionable takeaways based on sub-category profitability and discount impacts.

## 📊 Key Findings
1. **Category Performance:** The Technology sector drives the highest profit, whereas Furniture yields minimal profit despite significant sales volume.
2. **Sub-Category Outliers:** Copiers and Phones are highly profitable. Conversely, Tables and Bookcases operate at a substantial loss.
3. **Discount Impact:** There is a distinct negative correlation between the discount applied and the overall profit margin.

## 🛠️ Usage
To run this analysis locally:
1. Clone the repository.
2. Ensure you have the required libraries installed:
   ```bash
   pip install pandas numpy matplotlib seaborn
   ```
3. Open `Enhanced_Superstore_EDA.ipynb` in Jupyter Notebook or Google Colab.
4. Run all cells to view the insights and visualizations.
